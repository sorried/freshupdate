# freshGram updates notify

telegram-бот, который сообщает о новых версиях [freshGram](https://github.com/Snowy-Fluffy/freshGram). не нужно следить за страницей релизов или подписываться на каналы.

## как пользоваться

1. открой [@freshupdbot](https://t.me/freshupdbot).
2. нажми "запустить" или отправь `/start`.
3. новые релизы будут приходить в этот чат автоматически.

ничего устанавливать и настраивать не нужно. бот работает только в личных сообщениях.

хочешь запустить отдельного бота со своим токеном? смотри [инструкцию по установке](INSTALL.md).

## что приходит

в уведомлении есть версия, дата публикации, краткое описание изменений и кнопка перехода к релизу. полное описание и файлы для скачивания находятся на странице релиза.

старые версии после подписки не рассылаются. их можно найти в [списке всех релизов](https://github.com/Snowy-Fluffy/freshGram/releases).

## команды

- `/start` включает уведомления и открывает кнопки со ссылками.
- `/about` показывает информацию о freshGram и боте.

чтобы отключить уведомления, заблокируй бота в telegram. чтобы включить снова, разблокируй его и отправь `/start`.

если часто отправлять одну и ту же команду, бот ограничит команды на 5 минут. уведомления о релизах при этом продолжат приходить.

## данные и связь с проектом

бот хранит твой telegram id для отправки уведомлений, время обращений и состояние подписки. имя, username, телефон и текст сообщений не сохраняются.

это независимый бот, он не связан с командой freshGram.
